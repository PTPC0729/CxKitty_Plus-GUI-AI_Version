CxKitty 0.5.0 · Windows x64

解压后双击 CxKitty.exe，无需安装 Python。
请放在有写入权限的文件夹中。

本压缩包不含配置文件、账号、Cookie、密码、AI 参数、密钥、题库、缓存、进度或日志。
初始状态未登录。AI URL/模型/密钥、自定义 REST 地址为空。
默认视频 1 倍速，每 58 秒上报，任务间隔 15 秒。
应用内置 xxt_helper.ico，EXE、窗口和任务栏使用同一图标。

使用顺序：登录 → 课程自动加载 → 配置所需题库/AI → 选择章节起点 → 开始处理。
“＋ 新建页”创建独立任务页，沿用最近一次成功手动登录的账号。
各页分别选课运行；暂停、停止、关闭一页不影响其他页。
同一账号的同一课程不能重复启动。

使用过程中产生的配置、账号、密钥、缓存和记录保存在 EXE 旁边，更新时请保留。
如需独立数据目录，可通过 --data-dir 指定，或使用 CXKITTY_DATA_DIR 环境变量。
请不要将用过的程序目录重新打包上传；公开分发应使用原始发布附件。
