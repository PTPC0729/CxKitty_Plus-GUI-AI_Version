## CxKitty 0.5.0

### 功能

- 浏览器式多任务标签页；各页独立登录、选课、配置、暂停与停止。
- 新页继承最近一次成功手动登录的账号；已有页面会话保持独立。
- 登录后自动加载课程和章节，支持指定起始章节、跳过已完成内容及顺序处理后续课程。
- 支持视频、文档与文字章节测验，提供 JSON/SQLite/REST 题库和 AI 自动答题配置。
- 修复视频续接进度单位、上报 HTTP 403、登录有效性误判、章节统计与测验参数问题。
- 增加重复课程启动保护、共用数据写入保护及后台任务安全关闭。
- EXE、窗口与任务栏统一使用指定的应用图标。

### 下载

- `CxKitty-0.5.0-windows-x64.zip`：推荐，解压后运行，包含 EXE、使用说明和许可证。
- `CxKitty-0.5.0-windows-x64.exe`：单独的可执行文件，无需 Python。
- `CxKitty-0.5.0-source.zip`：与本版 EXE 对应的完整源码。
- `SHA256SUMS.txt`：以上文件的 SHA-256 校验值。

### 初始状态

公开成品不携带配置文件、账号、Cookie、密码、AI 参数或密钥、题库、缓存、进度和历史日志。首次启动未登录；可留空的服务设置为空，其余采用内置通用默认值。使用者需自行登录，并按需要配置题库或 AI。

更新时保留自己的数据，仅替换程序文件。重新分发请使用原始发布附件，避免将使用后产生的个人文件一并上传。

### 验证与源码

通过源码回归测试及实际 Windows EXE 的离线功能自检，覆盖多任务并发、账号继承、AI 模拟接口、二维码、视频协议和数据兼容。检查不登录真实账号、不调用付费模型；实际课程功能仍依赖平台及网络服务。
